# Agent Roles

This directory contains the durable responsibility, evidence, and safety boundaries for the Investigator, Implementer, Reviewer, QA, and Release Manager roles.

The PM/CTO assigns a scoped task to a role, reads its durable handoff, and decides whether to return it for correction or advance it. These role files do not grant production deployment authority and do not require the Founder to relay prompts or reports between workers.
