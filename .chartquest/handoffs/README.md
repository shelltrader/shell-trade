## TASK

[Task requested]

## CONTEXT

[Relevant system, constraints, decisions, and sources]

## CURRENT STATE

[Verified state and explicitly marked unknowns]

## WORK COMPLETED

[Completed work and evidence]

## FILES TOUCHED

[Exact files; state “None” for investigation-only work]

## TESTS RUN

[Command, result, build, and any skipped checks]

## KNOWN RISKS

[Open risks, concurrent-worktree concerns, and production uncertainty]

## NEXT ACTION

[Single next action or required decision]

## DO NOT TOUCH

[Out-of-scope files, systems, or external environments]
